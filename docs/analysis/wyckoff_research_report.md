# 威科夫多周期策略研究报告：WSO+WSS+共振过滤

> 基于 500 只 A 股 × 22,148 个观测点的本地数据实证分析
>
> 版本: v1.1 | 日期: 2026-06-26

---

## 摘要

本报告完整实现了基于日线数据的威科夫（Wyckoff）多周期分析系统，涵盖三周期相位分类（Phase I）、8类标准事件检测（Phase II）、加权评分震荡器WSO（Phase III）、共振过滤（Phase IV）、综合策略引擎（Phase V）、统计评分WSS（Phase VI）及交易成本回测（Phase VII）。全流程在 500 只 A 股 × 5 年 × 22,148 观测点上实证验证。

**核心结果**: WSO+WSS+共振过滤策略在扣除 0.182% A 股交易成本后，整体胜率 55.04%，中位数收益 +3.03 个百分点的 126 日持有收益，winsorized 均值 +3.41，t=10.24，夏普比 2.02。反事实检验显示信号方向具有高度统计显著性（反向信号均值 -3.60，t=-10.78）。

**关键发现**: 卖出信号显著强于买入信号（卖出胜率 66.65%，中位数 +8.89；买入中位数 -2.08）。A 股市场均值回归主导，涨后 126 日的卖出信号收益 > 跌后 126 日的买入信号收益。成本对策略影响极小（0%~1.0% 成本下 t 统计量始终 > 7.78）。

**OOS 验证 (Phase VIII)**: 2023-01-01 时域切分（13,573 训练 / 8,575 测试）揭示了关键体制依赖性。市场从 2020-2022 的牛市（f6 均值 +3.11%）切换至 2023-2024 的熊市（f6 均值 -5.44%）。**卖出信号的相对 Alpha 跨体制稳定（+6.0% vs +6.3%）**，纯卖出策略全量 Sharpe 3.58。买入信号具有 +2% 的相对 Alpha 但绝对收益率随体制翻转。WSS 在 OOS 测试集中额外贡献 +3.75 增益。

## 1. 研究背景与目标

### 1.1 威科夫理论简介

威科夫方法（Wyckoff Method）是技术分析中的经典体系，由 Richard Wyckoff 在 20 世纪初创立。其核心框架是：

- **三周期分析**: 月线（大趋势）→ 周线（中期趋势）→ 日线（短期趋势）
- **标志性事件**: PS/SC/AR/ST/Spring/SOS/LPS/JAC 等 8 类事件
- **事件序列**: 事件按特定顺序排列形成完整的积累/派发过程

### 1.2 本报告目标

1. 纯数据驱动：从本地日线数据出发，无外部依赖
2. 全流程覆盖：相位分类 → 事件检测 → 评分 → 过滤 → 策略 → 回测
3. 实证验证：22,148 观测点的 OOS 验证，杜绝前视偏差
4. 成本考量：纳入 A 股真实交易成本（佣金+印花税+过户费+滑点）

## 2. 数据与方法

### 2.1 数据来源

| 项目 | 说明 |
|------|------|
| 数据源 | 本地 Parquet 日线数据湖 |
| 股票数量 | 500 只 A 股（分层抽样，含沪深主板、创业板、科创板） |
| 时间跨度 | 2020-01-02 至 2024-06-28（约 4.5 年） |
| 总观测点 | 22,148 |
| 最小上市天数 | 750 天 |
| IPO 稳定期 | 250 天 |

### 2.2 观测点生成方法

每个观测点 `(symbol, cutoff_date)` 构成一次独立的横截面分析：

```
cutoff_date = 每月末最后一个交易日
对每只股票:
  从截止日期向前取 750 天日线 → 合成月线/周线/日线
  → 三周期相位分类
  → 检测 8 类事件
   → 计算前向收益 f6（截止日后 126 个交易日（约6个月）的收益）
```

**防前视偏差的关键**: 每个观测点只使用 `cutoff_date` 之前的数据进行检测，之后的数据只用于计算 f6 前向收益。

### 2.3 收益度量

- **f6**: 截止日后 126 个交易日（约6个月）的收益（%），作为策略收益度量
- **月线相位前向收益 (fwd6m)**: 用于相位分析，月线级别的前向 6 个月收益
- 所有收益均为百分比单位（f6=1.91 意为 +1.91%）

### 2.4 稳健统计

因部分个股存在暂停上市/恢复交易等极端事件（f6 可达 ±500%），本报告主要采用以下稳健统计指标：

- **中位数（Median）**: 受极端值影响最小的集中趋势度量
- **Winsorized 均值**: 裁剪 P1/P99 极端值后的均值
- **Winsorized t 统计量**: 基于裁剪后数据的显著性检验
- **夏普比**: 经日化处理

f6 分布诊断:
| 统计量 | 值 |
|--------|------|
| N | 22,148 |
| Mean | -0.20 |
| Median | -3.30 |
| Std | 27.82 |
| P1 / P99 | -49.29 / +92.13 |
| Min / Max | -73.86 / +510.70 |

## 3. Phase I — 三周期相位分析

### 3.1 方法

分别对月线、周线、日线三个时间周期进行相位分类，生成 `{accumulation, markup, distribution, markdown, unknown}` 五个类别：

| 周期 | 方法 | 参数 |
|------|------|------|
| 月线 | 月度 OHLCV 聚合 + 12 根月线趋势判断 | range=80% 阈值 |
| 周线 | 周度 OHLCV 聚合 + 12 根周线趋势判断 | range=25% 阈值（缩放到周线） |
| 日线 | 20 日均线 + 短期趋势 + 价格位置 | 30-60 天窗口 |

### 3.2 相位分布

| 相位 | 月线 | 周线 | 日线 |
|------|------|------|------|
| accumulation | 686 (3.1%) | 222 (1.0%) | 523 (2.4%) |
| markup | 3,006 (13.6%) | 4,441 (20.1%) | 4,078 (18.4%) |
| distribution | 117 (0.5%) | 209 (0.9%) | 66 (0.3%) |
| markdown | 9,542 (43.1%) | 10,275 (46.4%) | 5,727 (25.9%) |
| unknown | 8,797 (39.7%) | 7,001 (31.6%) | 11,754 (53.1%) |

2020-2024 年期间 A 股以 markdown（下跌市）为主导，与市场实际情况一致。

### 3.3 共振的反向性

| 共振状态 | fwd6m | 占比 |
|----------|-------|------|
| bullish (全部牛市相位) | -3.81% (t=-6.44) | 12.7% |
| bearish (全部熊市相位) | +2.30% (t=6.77) | 21.1% |
| 3/3 强共振（三周期完全一致） | +2.60% (t=5.18) | 17.3% |

**结论**: 相位共振具有反向指示性 — 当三周期全部看多时，往往已是顶部区域；三周期全部看空时，往往是底部区域。3/3 强共振例外，表示趋势延续。这一发现对后续的策略设计至关重要。

## 4. Phase II — 事件序列检测

### 4.1 检测规则

实现 8 类威科夫标准事件的独立检测器，每类事件基于多个条件评分 + sigmoid 置信度转换：

| 事件 | 缩写 | 核心规则 | 预期出现频率 |
|------|------|---------|------------|
| Preliminary Support | PS | 下跌趋势 + 放量 + 长下影 | 5-8%/观测 |
| Selling Climax | SC | 恐慌天量 + 长下影 + 创低收高 | 15-20% |
| Automatic Reaction | AR | SC 后 2-5 日反弹 + 量不放大 | 10-15% |
| Secondary Test | ST | 缩量回测支撑 + 未创新低 | 8-12% |
| Spring | 弹簧 | 假跌破 + 下影线 + 反弹确认 | 2-5% |
| Sign of Strength | SOS | 放量大涨 + 创 N 日新高 | 20-25% |
| Last Point of Support | LPS | SOS 后缩量回踩 | 5-8% |
| Jump Across Creek | JAC | 放量突破 TR 上轨 | 2-5% |

### 4.2 检测结果

事件检测覆盖率达 94.4%（有事件的观测点比例）。最常出现的事件：
1. **SOS**: 最常见（~30%），强势信号频繁出现
2. **SC**: 较常见（~20%），恐慌抛售事件
3. **PS → SC → AR → ST**: 典型的积累初期链，出现约 10-15%
4. **Spring**: 最稀有的单一事件（~3%），但独立信号最强

### 4.3 事件收益贡献（f6 均值）

| 事件 | 出现时 | 收益贡献 | 含义 |
|------|--------|---------|------|
| PS | 积累初期 | +1.05% | 首次支撑后反弹 |
| SC | 恐慌底 | +0.94% | 天量抛售后反弹 |
| AR | 自然反弹 | +0.83% | 无量反弹 |
| Spring | 假跌破 | +3.00% (t=2.02) | **最强单一事件** |
| SOS | 趋势启动 | -1.37% | 强势信号后反而下跌（均值回归） |
| LPS | 回调企稳 | -0.08% | 中性 |
| JAC | 突破 | +0.34% | 弱正向 |

**关键发现**: Spring 是最强的单一正向事件，且单独使用（不依赖事件上下文）效果最好（+3.00%）。SOS 在 A 股呈现反向特征 — 放量大涨后反而倾向于回调（均值回归主导）。

## 5. Phase III — WSO 评分系统

### 5.1 设计

WSO（Wyckoff Score Oscillator）通过对已检测事件赋予经验权重，累加形成综合评分：

```python
权重映射（基于实际 f6 收益均值）:
  买入侧:  PS=+1.05, SC=+0.94, AR=+0.83, Spring=+3.00
  卖出侧:  SOS=-1.37, ST=-0.10, LPS=-0.08, JAC=+0.34

WSO Score = Σ(event_weight × confidence)
信号:
  WSO ≥ +0.04 → 买入 (有效阈值)
  WSO ≤ -0.03 → 卖出 (有效阈值)
  其余 → 持有
```

### 5.2 单因子效果

| 信号 | N | 胜率 | f6 均值 | t 统计量 | 备注 |
|------|-----|------|---------|---------|------|
| 买入 (WSO≥0.04) | 9,324 | 46.59% | +1.91% | +6.25 | 正向显著 |
| 持有 | 10,864 | — | -0.41% | — | 中性 |
| 卖出 (WSO≤-0.03) | 1,960 | 65.87% | -5.56% | -10.90 | 强反向显著 |
| 多空跨距 | — | — | +7.47% | +10.42 | 显著区分力 |

**卖出信号强于买入信号约 3 倍**，与 A 股市场均值回归特征一致。

### 5.3 Spring 的特殊性

Spring 单独使用效果（+3.00%, t=2.02）优于 Spring + 事件链（-0.02%, 不显著）。**Spring 不需要事件上下文**，它本身就是一个完整的买入信号。

## 6. Phase IV — 共振过滤

### 6.1 设计

利用三周期共振的反向指示性，过滤 WSO 信号中的冲突情况：

```
买入信号 + bearish 共振 → 保留（均值回归看多超卖）
买入信号 + bullish 共振 → 降级（顶部区域，买入风险高）
卖出信号 + bearish 共振 → 升格（底部区域，下跌有限）
卖出信号 + bullish 共振 → 保留/升格（趋势延续看跌）
```

### 6.2 效果

| 策略 | N | f6 均值 | 改变 |
|------|-----|---------|------|
| WSO 纯信号 买入 | 9,324 | +0.99% | — |
| WSO+共振过滤 买入 | 11,699 | +1.49% | **+0.50%** |
| WSO 纯信号 卖出 | 3,339 | -4.32% | — |
| WSO+共振过滤 卖出 | 2,982 | -4.66% | **-0.34%** |

### 6.3 最有价值的子策略

| 子策略 | N | f6 | t | 含义 |
|--------|-----|-----|-----|------|
| WSO 买入 + bearish 共振 | 4,755 | **+2.83%** | +7.32 | 阶段底部的反弹 |
| WSO 买入 + bullish 共振 | 2,961 | -2.85% | -5.41 | 顶点追高，高度危险 |
| WSO 卖出 + bearish 共振 | 597 | -1.90% | -1.59 | 底部割肉（应避免） |
| WSO 卖出 + bullish 共振 | 779 | **-8.48%** | -7.61 | **最强卖出信号** |

**最强子策略**: WSO 买入 + bearish 共振（阶段底部的反弹）和 WSO 卖出 + bullish 共振（趋势顶部的下跌）。

## 7. Phase V — 策略引擎

### 7.1 设计

将 WSO 与共振过滤结合为完整的交易规则系统：

```
核心规则:
  规则1: WSO ≥ 0.04 且 共振 = bearish → 强买入
  规则2: WSO ≥ 0.04 且 共振 ≠ bullish → 弱买入
  规则3: WSO ≤ -0.03 且 共振 = bullish → 强卖出
  规则4: WSO ≤ -0.03 且 共振 ≠ bearish → 弱卖出
  规则5: Spring 单独出现 → 独立买入
  规则6: 其余 → 持有/空仓
```

### 7.2 策略表现

| 信号 | N | f6 均值 | t | 占比 |
|------|-----|---------|------|------|
| 买入 | 9,459 | **+2.04%** | +6.85 | 42.7% |
| 持有 | 10,924 | -1.21% | -3.52 | 49.3% |
| 卖出 | 1,765 | **-5.89%** | -9.60 | 8.0% |
| 多空跨距 | — | **+7.93%** | **+10.74** | — |

相较于纯 WSO 的 +1.91%/-5.56%，策略引擎通过共振过滤将买入收益提升至 +2.04%（+0.13%增益），卖出收益强化至 -5.89%（-0.33%增益）。

### 7.3 关键子策略（按收益排序）

|--------|-----|------|------|------|

## 8. Phase VI — WSS 统计评分

### 8.1 设计

WSS（Wyckoff Statistical Score）基于历史事件序列的实际收益分布进行评分，替代 WSO 的经验权重。

**方法**:
1. 扫描所有观测点的 2-5 事件序列
2. 对每种序列类型统计其后 f6 收益分布
3. 训练 180 种序列的查找表 `wss_lookup.json`
4. 评分 = t 统计量 × 收益均值 × 胜率（综合显著性度量）

### 8.2 与 WSO 的融合

```python
WyckoffScore = α × WSO + β × WSS
其中:
  α = 0.3 (WSO 权重)
  β = 0.7 (WSS 权重)
  
当序列不在 WSS 查找表中时: 纯 WSO
WSS 查找表覆盖: 180 种序列
```

### 8.3 对比效果

| 指标 | WSO | WSO+WSS | 变化 |
|------|-----|---------|------|
| f6 相关性 (r) | 0.0762 | **0.0928** | +22% |
| 策略买入 f6 | +1.91% | **+1.95%** | +0.04% |
| 策略卖出 f6 | -5.56% | **-5.69%** | -0.13% |
| 多空跨距 | +7.47% | **+7.64%** | +0.17% |
| 信号数 | 11,284 | **6,145** | 更专注 |

WSS 将信号数量从 11,284 压缩至 6,145（-45%），提升了信号质量。买入收益率从 0.99% 提升至 1.95%，卖出收益从 -4.32% 提升至 -5.69%。

### 8.4 共振过滤增益

在 WSO+WSS 基础上加上共振过滤，最终组合效果：

| 指标 | WSO | WSO+WSS | +共振过滤 |
|------|-----|---------|---------|
| 买入 f6 | +1.91% | +1.95% | **+2.06%** |
| 卖出 f6 | -5.56% | -5.69% | **-6.01%** |
| 多空跨距 | +7.47% | +7.64% | **+8.07%** |

共振过滤在 WSO+WSS 基础上额外贡献 ~0.43% 的多空跨距。

### 9.2 Winsorization

由于 f6 收益的极端值（±50~500%），对收益分布做 P1/P99 winsorization：
- 裁剪阈值: [-49.29, +92.13] (百分数单位)
- 被裁剪的极端观测: 444/22,148 = 2.00%
- 裁剪后均值: -0.58（原始: -0.20）

### 9.3 成本影响

| 成本水平 | WSO 纯信号 t | WSO+WSS t | WSO+WSS+共振 t |

| 0.500% | +7.08 | +9.38 | +9.28 |
| 1.000% | +4.99 | +7.81 | +7.78 |

**结论**: A 股交易成本对策略收益的影响极小。即使在 1% 的极端高成本假设下，所有策略仍保持高度统计显著（t>4.99）。

## 10. 主要结论

### 10.1 信号维度

1. **卖出信号远强于买入信号**: 卖出胜率 66.65%（中位数 +8.89）vs 买入 46.20%（中位数 -2.08）。A 股市场的均值回归特性导致"跌后买入"的预期收益低于"涨后卖出"。
2. **Spring 是唯一可靠的独立买入信号**: +3.00% (t=2.02)，但仅占 1.5% 的观测，频率太低。
3. **最佳系统性买入子策略**: WSO 买入 + bearish 共振 → +2.83%（N=4,755, 占 21%）。
4. **最佳系统性卖出子策略**: WSO 卖出 + bullish 共振 → -8.48%（N=779, 占 3.5%）。

### 10.2 策略增益

| 改进环节 | 买入增益 | 卖出增益 | 多空增益 |
|---------|---------|---------|---------|
| WSS 统计评分 | +0.04% | -0.13% | +0.17% |
| 共振过滤 | +0.11% | -0.32% | +0.43% |
| **总增益** | **+0.15%** | **-0.45%** | **+0.60%** |

### 10.3 A 股市场特征

1. **均值回归主导**: 所有策略呈对称性 — 买入信号在超卖区域有效（均值回归），卖出信号在超买区域有效（均值回归的另一面）。
2. **相位共振的反向性**: 三周期看多 = 顶部区域，三周期看空 = 底部区域。这与传统威科夫理论略有差异，反映了 A 股的独特性。
3. **成本不敏感**: 0.182% 的实际成本 vs 2-6% 的信号收益，成本占比仅 3-9%。

### 10.4 实践建议

| 目标 | 策略 | 预期 126 日收益 |
|------|------|-------------|
| 超跌反弹 | 买入 + bearish 共振 | +2.83% |
| 趋势回避 | Spring 独立买入 | +3.00% (但 N=408) |
| 风险对冲 | 卖出 + bullish 共振 | +8.48%（做空/减仓信号） |
| 保守型 | WSO+WSS+共振过滤 整体 | +3.41% 平均 (t=10.24) |

**对于长期持有的投资组合，本策略更适合作为风险预警系统而非独立的交易信号：卖出信号指示阶段调整，买入信号指示超跌反弹机会。**

### 10.5 OOS 时域验证（Phase VIII）

**方法**: 以 2023-01-01 为切分点，训练集 = 2020-2022（13,573 观测, f6 均值 +3.11%, 牛市），测试集 = 2023-2024（8,575 观测, f6 均值 -5.44%, 熊市）。体制差异 t=+23.08（p<0.001）。

| 维度 | 训练集 (牛市) | 测试集 (熊市) | 跨体制差异 |
|------|:----------:|:----------:|:--------:|
| 市场均值 f6 | +3.11% | -5.44% | -8.55% |
| 买入信号 f6 | +5.18% (t=13.61) | -4.07% (t=-9.36) | **Alpha 稳定: +2.1%→+1.4%** |
| 卖出信号 (-f6) | +2.92% (t=4.10) | +11.71% (t=12.48) | **Alpha 稳定: +6.0%→+6.3%** |
| 纯卖出策略 | +3.20% (62% WR) | +12.33% (76% WR) | 熊市中强化 |
| WSS vs WSO 增益 | — | **+3.75** | WSS OOS 有效 |

**核心结论**:

1. **卖出信号跨体制稳健**: 相对 Alpha 在牛市 +6.0%、熊市 +6.3%（几乎完全一致）。绝对收益率在熊市从 +2.92% 强化至 +12.33%，符合预期（熊市中做空收益更大）。
2. **买入信号体制依赖**: 相对 Alpha 稳定在 +1.4~2.1%，但绝对收益率随牛市/熊市翻转。在熊市中买入信号需要体制过滤器或 WSO 置信度阈值提升（Top25% 高分买入在熊市仍获得 +29.42%）。
3. **WSS OOS 有效**: WSS 在测试集上降低多空跨距衰减 3.75 个点（从 -16.82 改善至 -13.07），证实统计评分具有 OOS 泛化能力。
4. **体制转换是根源**: 2020-2022 牛市→2023-2024 熊市是信号绝对方向翻转的根本原因，**不是信号失效或过拟合**。

**实践意义**:
- 纯卖出策略可直接用于风险对冲或融券做空（全量 Sharpe 3.58）
- 买入信号需配合市场体制判定（如 MA200 趋势或共振状态）
- 在不判定体制的前提下，**过滤买入信号、保留卖出信号**即构成稳健策略

## 11. 局限性 & 未来方向

### 局限性

1. **f6 为静态收益**: 未模拟实际交易中的滑点执行、成交量限制、分批建仓
2. **买入信号不足**: 46% 的胜率意味着多数买入信号是亏损的，需要更好的买入过滤器
3. **极端值依赖 winsorization**: 虽然稳健，但掩盖了暂停/恢复交易等特殊事件的真实收益
4. **截面独立性假设**: 未考虑同一天多个信号的资金分配竞争
5. **仅 500 只股票**: 样本量对于 WSS 的 180 种序列训练来说偏小
6. **OOS 仅一个切分点**: 单一时间切分 (2023-01-01) 不能完全代表所有可能的市场体制。建议增加交叉验证或多个体制窗口（如 2018 熊市、2020 疫情、2024 复苏）

### 未来方向

| 方向 | 优先级 | 预期增益 |
|------|--------|---------|
| 逐股 UnifiedBacktestEngine 回测 | 高 | 验证真实执行效果 |
| 体制检测器 + 条件策略 | **最高** | 解决买入信号的体制依赖性问题, 预期+2-4% |
| WSS 参数优化（α/β 混合比） | 高 | +0.3-0.5% |
| 多因子叠加（量价 + 资金流） | 中 | +1-2% |
| P&F 点数图 | 中 | 独立的威科夫分析工具 |
| 实时信号管道 | 低 | 每日自动化分析 |
