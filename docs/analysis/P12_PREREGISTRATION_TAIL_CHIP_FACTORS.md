## 2. 因子定义与方向（跑数前冻结）

|---|---|---|---|---|---|

## 3. 参数面板与判定门限（与 P11 冻结完全一致）

## 4. 边界声明

1. 筹码字段为季频快照，变化率在报告期之间恒定（低频因子的固有滞后）；
   生效走保守披露偏移路径（比真实公告晚 ~2-8 周）。
2. cvar 在 60d 窗=最差 3 日均值，估计噪声大（预注册接受）。
3. 机构持股含被动指数成分（沪深300 纳入效应），非纯主动信号。
4. 其余同 P11 §8（单 regime、不复权 fwd 噪声、退市覆盖下界）。

### 关键发现

1. **max_drawdown_20d 是四批研究中最接近幸存的因子**: G1-G4 全过且 PBO=0.166
   为全批唯一达标, 但控 mom20 后残差 IC=−0.038、仅 6% 窗同向 → 深跌反弹的表观
   alpha 完全是动量 beta (深跌股=前期大跌股), 与 P3 reversal_20d (+0.0548 但
   PBO 0.669) 机制完全同构。
2. **尾部风险族方向全部正确但无一过 PBO**: cvar(+)/downside_semivol(−) 与文献
   预期一致, 确认 A 股左尾定价方向存在, 但窗口间稳定性不足且均被动量解释。
3. **筹码流三因子基本无信号**: 股东户数变化方向正确 (−)、PBO 0.166 优秀,
   但 |IC|=0.0094 差线败; 机构/十大流通变化率 |IC|<0.005 无预测力 ——
   季频低频信息在本面板 fwd5 视野下衰减殆尽 (视野错配, 如实记录不改判)。
4. **四轮独立收敛终局**: P2(GP 0/25) / P3(价量逻辑 0 通过) / P11(基本面 0/7) /
   P12(尾部+筹码 0/7) —— 截面预测力集中于动量的结论已覆盖数据挖掘、价量、
   基本面、尾部风险、筹码结构五个维度。按预案 §3: 因子挖掘正式终结,
   主线收敛 H-A 条件 illiq 工程化 (daily_signal_ha.py 生产化 + 实盘对账)。
