### 2.2 关键发现

**最大错误转换**: `accumulation→distribution` (74 次) 和 `distribution→accumulation` (63 次)。

这两个相位是**双向混淆**的——引擎在同一批股票上频繁互换 accumulation 和 distribution 标签, 说明这两个判定完全不可靠。它们不是"检测到真正的积累/派发", 而是"随机分配一个标签"。

**正确转换**: `accumulation→accumulation` (46) 和 `distribution→distribution` (52) —— 只有约一半的股票能在相邻期保持同一相位。

**正确周期转换**(严格 Wyckoff 周期):
- accumulation→markup: 34 次 (应最多)
- markup→distribution: 22 次 (应最多)
- distribution→markdown: 43 次 (应最多)
- markdown→accumulation: 5 次 (应最多)

**总体正确率: 39.6% (198/500)**。低于随机(50%)。

## 4. 根因诊断

### 4.1 检测器链优先级问题

检测器链是 winner-takes-all:
1. `_detect_markup` (MA 趋势) → 捕获趋势最好的股票
2. `_detect_distribution` (UTAD + TR) → 捕获趋势中等的
3. `_detect_markdown` (MA 下跌) → 捕获趋势较差的
4. `_detect_accumulation` (事件序列 + 启发式) → 仅捕获**剩余**的

这导致 accumulation 只能拿到 markup/distribution/markdown 挑剩的"最差标的"。在弱市中, 这些标的继续下跌。

### 4.2 PnF 主导 63.2% 相位

PnF hint 驱动 63.2% 的相位判定, 但 PnF 是**历史形态统计**(rising_lows/range_contraction), 不是**前瞻预测**。PnF 的 accumulation 标签只是"过去低点抬高"的描述, 不是"未来应上涨"的预测。

### 4.3 事件序列驱动路径虽然严谨但覆盖面低

事件序列(PS+SC+ST×2)路径严格符合 Wyckoff 理论, 但:
- 覆盖率低: 大部分股票不会触发完整的事件序列
- 触发后仍无 fwd 收益保证: 因为市场环境可能 override 事件结构
