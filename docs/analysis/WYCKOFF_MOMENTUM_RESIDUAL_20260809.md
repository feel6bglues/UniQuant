# Wyckoff 动量残差研究 — 计算 + 分析 + 红蓝对抗 + 判定

> 研究问题：`leader∧distribution` 相对 20d 相对动量（relmom）是否仍有独立增量？
> 触发：`WYCKOFF_FIX_REDBLUE_20260809.md` 对抗暴露"动量皮肤"嫌疑。
> 工具：`scripts/wyckoff_experiments/momentum_residual_analysis.py`（本报告专属新建，正式纳入仓库）
> 数据：三窗 as-of 回放（W1 04-30 / W2 03-31 / W3 05-29），全量池 n≈4760/窗，relmom = stk_20d − idx_300_20d 从数据湖日线重建。
> 日期：2026-08-09

## 一、计算方法（4 个正交检验）

| 方法 | 定义 | 回答的问题 |
|---|---|---|
| M1 分位残差 | relmom 10 分位桶内 `leader∧dist` vs 桶内其他，跨桶加权 | 控制动量后相位增量是否>0 |
| M2 OLS 残差 | `fwd_20d ~ relmom + relmom²` 拟合后取残差，组间 MWU | 非线性剥离动量后增量（更严） |
| M3 独有子集 | `leader∧dist` 中不属于 relmom-top10% 的部分 | 相位门在纯动量覆盖之外是否单独成立 |
| M4 网格 | relmom 5 分位 × leader 分组的 fwd 均值 | 动量×强弱交互是否存在 |

## 三、分析（计算数据的解读）

### 3.1 核心发现链

```
裸超额 +5.85/+4.09/+9.07   ← 三窗显著（之前判定）
   │ M1/M2 控制动量
   ▼
相位增量 +1.82/+4.34/+2.30  ← 也正（初判：有独立信息）
   │ R3 剔除 |fwd|>10% 右尾
   ▼
增量塌缩到 +1.06/+0.01/−0.24  ← 2/3 窗失去显著性，W3 转负
   │ 结论
   ▼
leader∧dist 的"独立 alpha"主要由右尾极端收益贡献
  = 少数暴涨股（>10%/20d）撑起，非位置偏移
```

### 3.2 三个决定性解读

1. **增量非稳健，是右尾依赖**：剔尾后 W2/W3 归零，M2 的 +4.34/+2.30 是少数 `fwd_20d>10%` 股票拉出的。这与之前发现的"leader 超额>0 占比仅 46-54%"一致——**均值正靠右尾，胜率约半**。
2. **分位内符号不一致**（R4）：W3 在 q6(−9.8pp) 和 q9(−1.7pp) 分位内相位增量转负，说明"相位门"在同动量桶内并不一致提升——是噪声而非机制。
3. **动量周期敏感**（R1）：W3 在 40d 周期转负，增量依赖"20d 恰好对齐"的巧合窗口，而非真实独立因子。

### 3.3 方法学自省
- M2 OLS 用了二次项仍无法解释右尾——尾部分布厚，OLS 残差均值仍被极值主导。
- M3 独有子集（+1.90~5.00%）虽然为正，但它本身就是"relmom 不在 top10% 的 leader∧dist"——即动量没这么强的股票，数量 n≈164-219 且同样被少数暴涨驱动（未剔尾检验，同样脆弱）。

## 四、红蓝对抗

### Round 1 — 蓝方（支持相位门有独立增量）

- **B1**：M1/M2 三窗全正（+0.91~+4.63pp），控制动量后仍>0 → "纯皮肤"假设初步证伪。
- **B2**：M3 独有子集三窗正（+1.90/+2.66/+5.00）→ 不在纯动量 top10 里的部分也正。
- **B3**：工程价值——即便增量弱，作为轻仓试探不亏损方向（对照全池 0）。

### Round 2 — 红方（反驳，获胜）

- **R1**：M2 的显著性未报告——补做 MWU 后（R3），剔尾前我没给 p；剔尾后 W2 p=0.96/W3 p=0.76 **全不显著**。
- **R2**：剔尾塌缩证明增量 = 右尾；3 个右尾股票就能改变 300 只组的均值，这不是稳健 alpha。
- **R3**：R4 分位内符号跨窗不一致 → "相位门"在同一动量桶内的作用是随机方向，机制不成立。
- **R4**：若真要落地，"轻仓试探"恰会捕获右尾暴涨（满仓）而收益被尾部主导——策略实际上在赌少数暴涨股，不是可复制的截面 alpha。
- **R5**：方法学质疑——分位残差 M1 的桶内 leader∧dist n 最小只有 5-9（q4/q5），统计功效极低，正号可能来自桶内少数样本抖动。

### Round 3 — 合流

蓝方被 R2/R4/R5 击溃：**增量存在但不可复制（右尾依赖 + 低功效分位 + 符号跨窗不一致）**。

## 五、判定与建议

### 判定：`leader∧distribution` 的独立 alpha **不成立（证伪）**

> 它作为"三窗显著正超额"成立，但该超额 **= 20d 相对动量 beta + 少数右尾暴涨股的运气**，控制动量并剔除右尾后 2/3 窗增量归零。之前"leader∧dist 是唯一真信号"的判定需下调为：**它是动量的一个实现，而非 Wyckoff 相位的独立贡献。**

### 建议（对 `WYCKOFF_FIX_REDBLUE_20260809.md` 的最终裁决）

1. **P0（distribution×leader 做多落地）——不落地**。证据不支持相位门带来可复制的独立增量；落地只会把动量因子的皮肤 + 右尾运气实装成引擎信号。
2. **若保留 leader 信号**，应作为**纯 20d 相对动量因子**使用（不做 Wyckoff 相位标签），且必须加**右尾/极端值约束**（如剔除 fwd 预测前 5% 或使用中位数/分位组合而非均值组合）。
3. **保留项不变**：P1-1 spring 降级观察、P1-2 结构分置信通路关闭（自身证伪，独立成立）、markdown 风控闸（唯一稳定方向）、P1-3 置信归一化、P2 工程卫生。
4. **新增研究任务**：对"右尾暴涨股"做归因——若它们集中在特定行业/小市值/事件驱动，应明确标注为不可交易的因子噪声；若可归因于稳定风格（如小盘动量），则用风格因子而非相位标签表达。
5. **最终方法论一句话**：
   > Wyckoff 相位标签（accum/dist/markup/markdown/spring）作为方向信号，在三窗横截面实证中**无一可复制正 alpha**；真正可测的截面收益来自 20d 相对动量，而 Wyckoff 结构分、相位、事件均无超越它的独立增量。Wyckoff 引擎应保留为**叙事/风控层**（markdown 闸、涨跌停、RR），从方向合成中**移除相位与 spring 作为独立开仓依据**。
