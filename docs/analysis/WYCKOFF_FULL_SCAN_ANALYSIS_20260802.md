# 全量 Wyckoff 扫描结果综合分析报告

> 分析视角：交易员 × 量化金融算法工程师 × 量化金融专家
> 数据源：`results/wyckoff_full/wyckoff_scan_all.csv`（2026-08-02 全量扫描，数据截至 2026-07-31）
> 原始样本：5382 只，5374 成功，8 只 too_short

---

## 一、执行摘要

本次全量扫描覆盖 5382 只标的，产出 5374 份有效分析。**核心结论：数据工程层面完成度高，但引擎信号的有效性与可交易性存在系统性缺陷，当前结果不能直接用于实盘决策。**

三重审计发现三大类问题：

1. **标的类型污染（数据层）**：175 只非 A股个股混入（可转债 40、ETF/LOF 124、B股 6、指数/特殊 5），其中 8 只进入"买入"信号
2. **置信度体系退化（引擎层）**：confidence 仅 3 个离散值，84% 标的为 D 级（0.3），无 A 级，结构评分高度拥挤（p25=58.7~p75=60.9），区分度差
3. **相位-收益背离（有效性层）**：accumulation 标的 6m 平均 -21%（理论应蓄势上涨），distribution 标的反而 1m +6.9% —— **相位分类与经典 Wyckoff 理论预期系统性背离**

## 二、数据质量审计（交易员视角的"安全第一"）

### 2.1 标的类型污染 — 175 只非个股

| 类型 | 数量 | 特征代码段 | 风险 |
|---|---|---|---|
| ETF/LOF | 124 | 159/160/161/16x/51x | 单位净值≠股票，价差/规则不同 |
| 可转债 | 40 | 123/127/11x/12x/13x | 转股机制，非纯股 |
| B股 | 6 | 200/900 | 外币计价，流动性差 |
| 指数/特殊 | 5 | 999xxx、000xxx.SH | 非交易标的 |

**8 只非个股进入"买入/做多"信号**（123072.SZ、127085.SZ 转债，159834/160610/161125 等 ETF，200030.SZ B股，999997.SH 指数）—— 若直接交易将产生灾难性后果。

**审计结论**：候选池过滤必须增加证券类型白名单（剔除非 A股个股段），当前 `candidates.csv` 的 306 只中含污染样本。

### 2.2 复权口径错配 — 4 只 target_1 严重失真

4 只 target/close > 5 的标的全部为 raw（未复权）状态且 close < 0.5：

| 标的 | close | target_1 | ratio | 问题 |
|---|---|---|---|---|
| 000004.SZ | 0.37 | 2.76 | 7.5x | 复权后深度折价，P&F 目标价未复权 |
| 002808.SZ | 0.23 | 2.83 | 12.3x | 同上 |
| 002898.SZ | 0.38 | 21.66 | 57x | 目标价失真 |
| 301196.SZ | 63.36 | 336.72 | 5.3x | 同上 |

**根因**：raw 标的的 `last_close` 是复权价，而 P&F count target 用未复权数据计算，两套口径混用导致目标价虚高。这些标的的风险收益比（target/close 中位 1.05）被严重高估。

### 2.3 全市场个股价格分布

- 5199 只干净个股中 87 只（1.7%）close < 2 元（ST/低价退市风险），已污染候选池 22 只（7%）
- 低价股（<2元）的 Wyckoff 信号可信度天然偏低（流动性差、ST 规则复杂）

## 三、置信度体系诊断（量化算法工程师视角）

### 3.1 confidence 三值退化

```
confidence: 0.3(D) 占 84.1% | 0.5(C) 占 14.3% | 0.7(B) 占 1.6% | 无 A 级
```

**解读**：confidence 取值离散化为 3 档，且 84% 落在最低档。这不是"市场差"的充分解释——更多反映**置信度评分缺乏中间层区分**。真实市场的置信度应是连续分布，当前体系把大量"中等可信"信号压入 D 档。

### 3.2 结构评分天花板效应

```
structural_score: p25=58.7, p50=60.0, p75=60.9, max=64.4, std=4.3
```

**结构性缺陷**：评分 58-62 区间高度拥挤（占约 70%），max 仅 64.4 分，无 ≥70 分标的。`_compute_structural_score` 的 min-max 归一化在有天花板约束时失去区分能力——**评分对信号排序几乎无贡献**（confidence vs structural_score 相关性仅 -0.02）。

### 3.3 置信度与结构评分的脱节

```
pearson(confidence, structural_score) = -0.024 (近乎零)
```

两个本应正相关的质量指标完全独立，说明**信号排序维度冲突**：高结构评分的标的并不必然高置信，反之亦然。当前无加权融合机制，导致候选池排序无稳定的优先级。

## 四、信号有效性分析（量化金融专家视角）

### 4.1 关键信号-方向脱节

| 信号类型 | 数量 | 给出"买入/做多"数 |
|---|---|---|
| spring | 66 | **0** |
| accumulation（相位） | 227 | **0** |
| distribution（相位） | 326 | **0** |
| markup | 62 | **17** |

**Spring 是 Wyckoff 理论最强的买入信号（下跌末端的弹簧），但 66 只检测到 spring 的标的 0 只给出"买入"方向**（42 只"观察等待"、24 只"空仓观望"）。而本应追高风险最大的 markup 却给了 17 只"买入/做多"。

**这与经典 Wyckoff 完全相悖**：
- ✅ 应在 accumulation 后段 / spring 确认后买入
- ❌ 不应在 markup（已上涨阶段）追高买入

### 4.2 相位-收益系统性背离（决定性证据）

对 200 只随机抽样标的计算相位对应的实际收益：

| 相位 | 1m 收益 | 6m 收益 | 理论预期 | 实际背离 |
|---|---|---|---|---|
| markdown | -13.6% | -28.1% | 下跌 ✅ | 一致 |
| accumulation | -6.8% | -21.0% | 蓄势待涨 | **背离** |
| distribution | +6.9% | -9.5% | 见顶回落 | **背离** |
| markup | +5.8% | -11.1% | 继续上涨 | 背离 |
| unknown | -31.6% | -22.6% | — | 最差 |

**统计结论**：除 markdown 外，各相位的实际收益方向与 Wyckoff 理论预期不一致。accumulation 标的平均 6m 下跌 21%，distribution 标的 1m 反而上涨 6.9%。这说明当前引擎的相位分类更多反映**过去的统计形态**，而非**未来的前瞻信号**。

### 4.3 Spring 信号标的走势验证

抽样 10 只 spring 标的的近期走势高度分化：1m 从 -16.1% 到 +16.4%，6m 从 -32.7% 到 +14.9%。**无稳定的正收益预期**——即使引擎给出 spring，标的后续走势也无保证。这符合 Wyckoff 研究的历史结论（Spring→BUY 理论信号从不触发，实际信号 4.5% 罕见且追涨）。

| 置信度 | C 272 / B 33 / A 0 |

### 5.2 风险收益比分布

```
target_1/close: 中位 1.05, p75 1.21, max 3.82
```

**问题**：候选池中位风险收益比仅 1.05（目标价仅比现价高 5%），对扣费（佣金+印花税+滑点 ≈ 0.3-0.5%）后几乎无利润空间。即使方向正确，盈亏比也不支持交易。**这是候选池最大的可交易性缺陷**。

### 5.3 高价值候选（B级 + leader + spring）

仅 7 只：000938.SZ、002224.SZ、002445.SZ、002753.SZ、600512.SH、601865.SH、603288.SH。这些是相对最强的组合，但即使它们也**无 1 只给出买入方向**，且多数 target 仅高出现价 3-5%。

## 六、市场环境解读（交易员视角）

当前（2026-07-31）A股市场的 Wyckoff 相位分布：

- **distribution 46.2%** —— 近半个股处于派发阶段，市场整体偏防御
- **accumulation 25.2%** —— 约四分之一个股有吸筹迹象
- **markup 2.6%** —— 极少个股处于明确上涨阶段
- **systemic_decline RS 64.7%** —— 三分之二个股弱于大盘

**交易含义**：市场处于**宽幅震荡偏弱**格局。46% 派发 + 65% 系统性走弱意味着**当前不是进攻性买入窗口**，应以防御/观望为主，精选少数 B级 accumulation/leader 标的建立观察仓。

## 七、综合结论与行动建议

### 7.1 结论（三视角汇合）

| 维度 | 结论 | 严重度 |
|---|---|---|
| 数据质量 | 标的污染 + 复权口径错配 | 🔴 高 |
| 置信度体系 | 3值退化 + 评分天花板 + 维度脱节 | 🔴 高 |
| 信号有效性 | spring 不给买入 + 相位-收益背离 | 🔴 高 |
| 候选池可交易性 | 风险收益比 1.05 无利润空间 | 🟠 中高 |
| 市场环境 | 派发主导 + 系统性走弱 | 🟡 中性（反映真实） |

### 7.2 行动建议（按优先级）

**P0 — 数据层修复（1-2天）**
1. 候选池加入**证券类型白名单**（剔除 159/16x/123/127/200/999 段）
2. raw 标的统一复权口径（target_1 用复权价重算或标注不可用）
3. 剔除 close < 2 元的 ST/低价股或单独标注

**P1 — 引擎层修复（3-5天）**
1. **修复 spring→买入的传导**：spring 检测到但交易计划从不给"买入"，需排查 `_step5_trading_plan` 的信号门控逻辑
2. 置信度改为**连续评分**（当前 3 值离散失去区分度）
3. 结构评分突破天花板（当前 max 64.4，缺乏区分力）
4. 融合置信度与结构评分的**单一排序指标**

**P2 — 有效性验证（1-2周）**
1. 对候选池做**前瞻收益检验**（signal → fwd 20d/60d 收益），量化各相位的真实 Alpha
2. 与 walk-forward 历史结论交叉验证（该研究已证明 Wyckoff 买入信号罕见但真实，仅 4.5%）
3. 用 bootstrap 构建置信区间，验证相位-收益背离是否显著

### 7.3 交易员底线建议

**当前全量扫描结果不可直接交易**。在 P0 数据净化 + P1 信号传导修复完成前：
- ❌ 不依据 spring/accumulation 信号建仓
- ❌ 不采用 candidates.csv 直接选股
- ✅ 可将 7 只 B级+leader 标的作为**观察池**跟踪
- ✅ 相位分布可作为**市场状态温度计**（46% 派发 → 防御）

> 核心判断：这次扫描的价值在于**暴露了引擎与真实市场的数据鸿沟**，为下一步修复提供了精确的靶点。修复后的重扫才能产出可交易的候选池。
