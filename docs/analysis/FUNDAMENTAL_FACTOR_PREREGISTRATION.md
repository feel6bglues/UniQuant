# P11 基本面价值/质量因子族 — 预注册 (先于跑数冻结)

> **冻结时间**: 2026-08-26（实施代码与本文档先于任何真实数据因子结果产出）
> **前置**: P1-P10 十轮证伪闭环；P4 财务底座（5211 只 × 42 季 × 577 列）；
> P5 已证伪 roe/a_cagr3/c_single_yoy 等 5 个成长质量因子（全部 FAIL 四重门）
> **测试脚本**: `scripts/factor_mining/run_fundamental_factor_test.py`
> **方法论基线**: 与 P3 (`run_logic_factor_test.py`) 完全同参数面板，保证横向可比

## 1. 研究问题

在控制动量 beta 后，A 股是否存在独立的价值溢价与质量/应计溢价？

背景约束：本项目已确立"A 股截面预测力高度集中于动量"（P2/P3），且
"高质量→高收益"在本窗口整体不成立（P5 成长陷阱实证：roe@fwd63 IC=−0.0780、
a_cagr3@fwd63 −0.0808）。因此本预注册对质量类因子**同时登记对立假设**。

## 3. 数据口径（实测锚定后冻结）

| 字段 | TDX 存储口径 | TTM 方法 |
|---|---|---|
| 营业收入 / 其中：营业成本 | 单季值 | rolling(4).sum() |
| eps / 归母净利 / OCF / 每股OCF | 累计 YTD | 年边界差分 → rolling(4).sum() |
| bps / 总资产 / 总股本 / 自由流通股 | 时点存量 | 不做 TTM |

锚点验证（2026-08-26）：600519/000001.SZ/300750/002594/601318 五只 2024 年报——
营收四季加总与披露值精确一致（比亚迪 7771 亿、平安集团 10289 亿等）、归母净利
年内单调递增且 Q4=全年、茅台 eps_ttm@FY2024=68.64。

**PIT 处理**: merge_asof backward on effective_date = 财报公告日期（缺失时回退
报告期 + 披露窗偏移: Q1+3mo/Q2+2mo/Q3+3mo/Q4+4mo）。当前档案公告日列为浮点
YYYYMMDD.0 格式 → 全部走偏移回退路径，属保守（生效日偏晚），无未来信息泄露。
单元测试锁定该行为（`test_merge_financial_metrics_merges_and_ttm` 断言尾日
不可见未生效年报）。

**价格口径**: 日线湖为不复权原始价，财务为披露时点名义值 → EP/BP/CFP/SP
比值时点正确。副作用：fwd 收益含除权跳空噪声，与 P1-P3 口径一致（横向可比优先）。

## 4. 参数面板（与 P3 冻结一致）

## 5. 判定门限（四重门 + 方向, 冻结）

对每个因子（17 个窗口的 OOS IC 序列）：

| 门 | 标准 |
|---|---|
| G1 IC | \|mean(OOS IC)\| > 0.01 |
| G2 ICIR | \|ICIR\| > 0.5 |
| G3 PBO | 块自助(2000次, seed=42) < 0.2 |
| G4 方向 | sign(mean IC) == 预期方向 |
| G5 动量残差 | 控 mom20 秩回归后残差 IC>0 ∧ 剔右尾(top10% momentum)IC>0 ∧ ≥2/3 窗口同向（按预期方向翻转符号） |

**幸存标准 = G1∧G2∧G3∧G4∧G5 全过。** 任一门 FAIL 即判 FAIL，
不做事后门限调整、不因单因子失败改面板。

## 7. 失败预案

- 若 F5 gross_profitability 整体 IC ≤ 0：按登记的对立假设记录
  "A 股质量溢价不存在/被反转结构覆盖"，与 P5 结论合并叙事，不追加窗口重测。
- 若全部 7 因子 FAIL：确认基本面赛道在本窗口无独立 alpha，
  因子研究主线收敛至 H-A 条件 illiq 工程化（daily_signal_ha 生产化）。
- 若部分通过：进入 P12 —— regime 条件化复检（trend×vol 六格）+
  与 H-A 的组合增量测试（同 P8 三臂框架加 STRAT-D 臂）。

## 8. 边界与局限（预先声明）

1. 幸存者偏差：财务档案来自当前可得 5211 只，退市股覆盖不全（下界影响）。
2. 公告日浮点格式 → 全量走保守偏移路径，信号生效日系统性偏晚 ~2-4 周
   （压低而非虚增因子表现，属保守偏差）。
3. 不复权价格使 fwd 收益与反转/波动类因子带除权跳空噪声（历史既定口径）。
4. 单一窗口 regime（2019-10→2026-05），跨周期外推有效性未知（P9 同款警示）。
5. 自由流通股为季频快照，turnover_20d 季内近似恒定分母。

**裁决: 0/7 幸存 (按冻结判据, 不改判)。**

### 关键发现

1. **方向门 7/7 全对**: 价值正 (bp/sp/cfp/ep)、应计负、换手负——A 股基本面异象的
   方向结构与文献一致, 数据底座与口径实现得到方向面验证。
2. **动量残差门再次全灭价值族**: 控 mom20 后 bp/sp/cfp/turnover 残差 IC 全部翻负
   (pos_frac 低至 0-6%)——表观价值溢价完全由动量 beta 解释 (低 BP/高 SP 股 =
   前期跌多的反转股), 与 P3 max_ret/skew 机制完全同构。至此 P2(GP)/P3(价量逻辑)/
   P11(基本面) 三赛道独立收敛: **A 股截面预测力集中于动量的结论扩展到基本面维度**。
3. **质量溢价对立假设证实**: gross_profitability 是唯一过 PBO+动量残差门的因子,
   但原始 IC 为负——控制动量后高毛利公司略好, 整体"高质量→高收益"不成立。
   独立复现 P5 ROE 成长陷阱结论 (P5 roe@fwd63 −0.0780)。
4. **PBO 功效备注** (不改判): 本面板 17 窗下基线因子 PBO≈0.42 为常态水平,
   <0.2 可达但要求窗口间 IC 符号高度稳定; 价值族 ICIR 高而符号稳定性不足。
   属小样本功效限制, 如实记录。
5. 价值复合为 null (无组件过五门), 按预案 §6 仅记录。
