## 2. 三轮红蓝对抗

### Round 1: P&F 投票

**红队**: P&F 投票不能改善方向性。P&F-only 的 63% accumulation 会将噪声引入投票系统。

**蓝队**: P&F 投票可以减少检测器链的单一偏见，组合投票应该比单一检测器链更稳健。

**实证裁决: 红队胜**:
- P&F voted: 1/4 方向正确（与 chain-only 相同）
- P&F 的 63% accumulation 在投票中主导了相位判定
- P&F 不提供 markup/markdown 信号（0%），无法帮助方向判定
- **结论: P&F 投票不能改善方向性。P&F 应仅用于 TR 识别和目标价，不应参与相位判定投票。**

### Round 2: 反向共振

**红队**: 反向共振虽然方向正确，但分布极端（accum 53.1%, markup 0%）。这不是可用的相位分布。

**蓝队**: 方向正确是第一位的。分布极端可以通过调整阈值来改善（如要求 3/3 共振才反转，而非 2/3）。

**实证裁决: 蓝队胜**:
- 反向共振是**首个 4/4 方向正确**的方法，这是一个根本性的突破
- 方向反转问题自 2026-07-23 的 walk-forward 分析以来一直未解决，反向共振首次证明可以解决
- 分布极端问题是**阈值问题**，不是方法问题。要求 3/3 共振才反转可有效控制分布
- **结论: 反向共振是方向反转修复的正确方向。需要调整共振阈值从 2/3 到 3/3 来控制分布。**

### Round 3: 因果链假设

**红队**: 你无法验证因果链，因为你没有事件数据。你只是在用简单趋势模型（st<-0.05 vs st>0.05）做替代。

**蓝队**: 简单趋势模型（t=13.138, p=0.0000）显著优于链式相位（t=0.379, p=0.3523），证明"基于上下文的简单规则比引擎的复杂检测器链更有效"。这间接支持了因果链假设。

**实证裁决: 蓝队部分胜**:
- 简单趋势模型: 做多（st<-0.05）+2.06%, 做空（st>0.05）-1.02%, **t=13.138, p=0.0000** ✅
- 链式相位: accum +1.78%, dist +1.40%, **t=0.379, p=0.3523** ❌
- 简单趋势模型的市场预测力是链式相位的 **35 倍**
- 这证明了"更简单的上下文规则比复杂的检测器链更有效"，间接支持了"用上下文驱动的事件序列替代检测器链"的因果链假设
- **结论: 因果链假设被间接支持。需要事件数据直接验证。**

## 3. 修正方案

### 3.1 反向共振校准

**问题**: 2/3 共振阈值太宽松，导致 accum 53.1%。

**修复**: 区分 2/3 和 3/3 共振:

```python
def resonance_vote(monthly, weekly, daily):
    bullish = {"accumulation", "markup"}
    bearish = {"distribution", "markdown"}
    phases = [monthly, weekly, daily]
    bc = sum(1 for p in phases if p in bullish)
    bc2 = sum(1 for p in phases if p in bearish)

    if bc == 3:
        return "distribution"  # 3/3 看多 → 强反转信号
    if bc2 == 3:
        return "accumulation"  # 3/3 看空 → 强反转信号
    if bc == 2:
        return "unknown"  # 2/3 看多 → 不确定，交回月线
    if bc2 == 2:
        return "unknown"  # 2/3 看空 → 不确定，交回月线
    return monthly
```

**预期分布**: accum 10-15%, markup 5-10%, distribution 5-10%, markdown 10-20%, unknown 45-60%

### 3.2 三周期分类器优先级

**问题**: 当前合成周线/日线分类器过于简单（基于 short_trend 和 relative_position）。

**修复**: 不依赖合成数据，而是实际运行 `WeeklyPhaseClassifier` 和 `DailyPhaseClassifier`（已在 `phase_analysis.py` 中实现）。

### 3.3 因果链实现

**问题**: 无法直接验证因果链，但简单趋势模型证明上下文规则有效。

**修复**: 实现因果链评分器（LCS 算法），与 WSO 独立权重融合:

```python
final_score = α × causal_chain_score + β × WSO_score + γ × WSS_score
```
