## 1. 结论摘要（一句话）

**在"日线 OHLCV + A股涨跌停/T+1/幸存者数据"的客观约束下，Wyckoff 可实现边界 = 叙事/标注/风控层 + 结构评分；理论结构（P&F/事件/相位/RS/Count）全部可实现，盘口级"吸收"不可实现（数据分辨率下限），方向信号从理论（状态≠预测）与数据（无逐笔、fwd 受限）双重推导均为恒无。**

## 2. 方法论：为什么从客观条件出发

本研究的锚定顺序为 **客观条件 → 理论要求 → 可实现推导 → 目标方案**，而非"现有代码 → 审计差距"。理由：

1. 第一性原理要求：任何实现断言必须先回答"数据是否物理上支撑该计算"，再谈代码是否做到了；
2. 现有代码是否"对"不能由代码自身判定，只能由理论 + 数据判定；
3. 目标是得到**独立于历史实现路线**的目标态，防止实现惯性污染结论。

## 4. 第一性原理层：Wyckoff 理论对数据的"最低要求"

从理论原点（Wyckoff 三大定律 + 九步 + 事件 + 相位）推导每个构件**强制要求**的数据：

| 理论构件 | 理论定义所需 | 数据湖具备？ | 判定 |
|---|---|---|---|
| P&F 图（box / reversal / Count） | 价格极值序列 + box 尺寸策略 | OHLC ✓ | **可实现**，box 必须按价格自适应 |
| 三大定律（供需/因果/量价） | 价格 + 量的关系检验 | OHLCV ✓ | **可实现** |
| 九事件（PS/SC/AR/ST/LPS/SOS/UT/UTAD/spring） | 价格形态 + 量能确认 | OHLCV ✓ | **可实现**（日线粒度） |
| 四相位（accumulation/markup/distribution/markdown） | 事件序列 + 区间行为 | ✓ | **可实现** |
| 区间宽度 / Count 目标价 | P&F 区间 | ✓ | **可实现** |
| 相对强弱 RS | 个股 vs 基准指数 | 000300.SH ✓ | **可实现** |
| 事件量能确认（spring 量缩 / SC 放量） | 量对比 | volume ✓ | **可实现** |
| **"tape reading"（逐笔/盘口级吸收、抛压识别）** | **逐笔 / Level-2 / 挂单** | ✗ 无 | **不可实现** —— 原著核心操作手段，日线只能用量价代理 |
| 成交量分布 / 成本区（POC） | 日内 / 逐笔分布 | ✗ | **不可实现**（日线只能近似） |

**第一性原理结论 A**：Wyckoff 的**理论结构在日线 OHLCV 上完全可实现**；唯一系统性缺口是"盘口级吸收"——这解释日线引擎只能产出**叙事/标注**，无法还原原著所需的逐笔证据。**这不是实现缺陷，是数据分辨率决定的理论下限。**

## 5. 从数据推导可实现目标态（推导 1–7）

### 推导 1 — box 尺寸必须按价格自适应 ✅（已补验，见 §6.1）
价格跨 ¥0.5–2600 三个量级，固定绝对 box 在低价股失真、高价股失效。推论：box 必须是价格分数（ATR/close 或固定分数），3-box 反转。

### 推导 2 — 涨跌停 / 零量必须排除出"有机"样本 ✅（已落地，见 §7）
涨跌停日价格被交易所机制钳制（非供需自由定价），一字板更无自由成交。Wyckoff 假设自由定价，A股规则打破该假设 → 这些棒必须标 structural/non-organic，否则量价关系被污染。**这是客观规则，不是理论可选项。**

### 推导 3 — 平盘非涨停棒 ≠ structural
停牌/零成交造成的"平盘"是缺失态而非结构事件，应保持 organic（u=0、零 churn）。此条在 TRIAD-VSA 落地中从失败用例反推确认（常量价序列曾被整段误杀）。

### 推导 4 — 所有特征必须因果 trailing
第一性原理（无未来函数）公理：任何窗口统计只能用 `t` 及以前数据。与数据格式无关，是研究诚实性硬约束。

### 推导 5 — 幸存者偏置无法消除，必须显式标注 ✅（已定量核验，见 §6.3）
数据湖只有现存 5201 只，as-of 历史窗口缺已退市者。**2026-08-18 定量核验（type=1 纯股票口径）**：`all_stock_codes` 退市股票共 337 只，5 窗覆盖率 0.999–1.013（见 §6.3）→ 幸存者偏置对历史在市分母影响 ~0.3%，**每窗仅缺 ≤8 只退市股票**，无需重判既有统计结论。数据层不可消除，显式标注见预注册文档 §数据窗口。

### 推导 6 — 恒无方向
Wyckoff 事件/相位是**状态描述**（"现在处于什么结构"），理论本身不提供"下一根必涨/必跌"的机械规则（原著是盘口主观判断）。从第一性原理，日线引擎目标态 = **叙事 + 风控层**，不产方向入场信号。数据分辨率（结论 A）与理论（推导 6）两层互相印证。

### 推导 7 — 验证门槛必须匹配数据能力 ✅（已补验，见 §6.2）
fwd 收益检验只能在 2026-07-23 之前做；老窗（2024-12-31 / 2025-06-30）fwd_60d 完全可用，新窗（2026-04-30 后）fwd_60d 受限或为空 → **预注册阈值（≥2/3 窗 MWU p<0.05）正是为受限数据设计的纪律**。

### 6.1 推导 1：`src/uniquant/brain/wyckoff/pnf.py` box 策略

## 9. 结论与开放项

### 结论
Wyckoff 在**日线 OHLCV + A股规则**下的可实现边界 = **叙事/标注/风控层 + 结构评分**。理论结构（P&F/事件/相位/RS/Count）全部可实现；盘口级吸收不可实现（数据分辨率下限）；方向信号从理论（状态≠预测）与数据（无逐笔、fwd 受限、T+1）双重推导均为**恒无**。现有实现的 P0 方向根除与有机判定与第一性原理推导吻合。真正的客观边界是**幸存者偏置不可消除**、**fwd 窗口受限**、**数据卫生（指数未归档）**，而非代码细节。
