## R1 方法论红队

### R1-1 [CRITICAL] 幸存者偏差的方向性与 CANSLIM 正面冲突

**问题**：P4 已实测证明 TDX 财务归档按当代代码池重建（欣泰电气连在市时期的归档都不在）。CANSLIM 是"买入强势成长股"策略——其天然的反例恰恰是**曾满足 C/A 条件后来暴雷退市的股票**（乐视网、康美药业、康得新均为当年高成长明星）。这类股票从回测样本中消失 = **只保留成长成功的案例 = 系统性高估 CANSLIM 表现**。

**量化直觉**：华创回测最大回撤 45.5% 尚且是在含退市股的 Wind 全样本下；本项目样本若缺暴雷股，回撤与尾部风险将被低估，而收益端几乎不受损——**偏差方向单向有利**。

**证据链**：
- `FINANCIAL_DATA_ACQUISITION_PLAN.md` §5: "00x 段股票数跨期恒为 412 → 归档疑似按当代代码池重建"
- P1 幸存者披露：type=1 口径退市股仅 337/5541 (~6%)——但这是**数量占比**，不是**收益影响占比**；暴雷股贡献的是极端负收益尾部

**修正要求**：方案必须增加 §"幸存者偏差敏感性分析"作为必做项：(a) 用 baostock `query_all_stock(day)` 历史快照（可取任意历史交易日全名单）量化各期"在市但无财务数据"的比例；(b) 构造最坏情形边界：假设缺失股票收益为 -100%~-60% 区间，给出组合层收益的下界估计；(c) 在报告中强制披露。

### R1-2 [HIGH] H3 预设失败 = 给 L/N 发"免死金牌"后又用它，逻辑不自洽

方案预注册写道"H3: L/N 独立 IC 为正但不过动量残差门（复现 P3）"。把**预期失败写进预注册**产生双重问题：(a) 若 L/N 真失败，可以说"符合预期"；若意外通过则是"新发现"——**两头堵，不可证伪**；(b) 既然预期 L/N 无独立 alpha，为何还允许它进入最终系统？需要明确的准入逻辑而非模糊表述。

**修正**：H3 改为中性双向判定："L/N 独立四重门结果如实记录"；并新增明确规则——**L/N 进入最终系统的唯一理由是 H4（CA 条件子集内的组合增量 >0），不因其'符合预期'而自动豁免或自动入选**。

### R1-3 [HIGH] 多重检验预算缺失

主假设 6 个之外，方案散布大量参数敏感性：C 门槛 18%/25%、N 距离 10%/15%/20%、RPS 加权变体、M 的 MA200/RegimeDetector 两版……实际假设检验数 ≥15。PBO 门控只在因子层出现，**参数选择层的多重比较校正完全没有提**——这正是本项目 Wyckoff 研究"X4 单窗显著被误读"的老路。

**修正**：声明"参数敏感性仅作稳健性报告，不作为选择依据；所有门槛在看到任何回测结果前冻结为主版本值（C≥25%、N≤15%、RPS≥80、MA200）"；若必须调参，扣 Bonferroni 或报告全部网格而非最优格。

### R1-4 [MEDIUM] 因子层 IC 框架对低频基本面因子天然不利，H1/H2 判定可能假阴

C/A 信息每季更新一次，日度 IC 序列高度自相关且大部分时间"无新信息"，有效样本远小于名义 1600 日×17 窗。直接套用日频 ICIR>0.5 门槛对季度更新因子偏严，可能导致 H1/H2 假阴性误杀。

**修正**：因子层对 C/A 采用**季频事件对齐评估**（以财报公告日为事件的 FwdRet 分层）作为与日频 IC 并行的第二判据；两者结论冲突时以事件法为准并说明。

## R2 数据与实现红队

### R2-1 [CRITICAL] 行业过滤不可行——无历史行业数据，现价快照即前视

**实测证据**：
- 财务 parquet 577 列中**无行业列**（TDX 归档不含）
- 日线行情列仅 `date/open/high/low/close/amount/volume/reserved/code`
- `brain/factors/industry_provider.py:get_industry_dummies()` 用 `ak.stock_board_industry_name_em()`——**今天的行业归属快照**

用今天的行业标签去过滤 2016 年的历史样本 = 前视偏差（公司行业会迁移：如某股当年属化工现属电子）；且金融股（银行 42 只 + 券商保险）的 C/A 科目差异是方案自己承认要过滤的。

**修正**：(a) 一期放弃行业过滤，改为**科目级防御**：金融识别用规则近似（代码段 600xxx 中 601939/601288 等 + 财务特征：debt_ratio>80% 且 revenue/total_assets<10% 判银行）→ 不完美但无前视；或 (b) 二期拉取申万历史行业成分（akshare `index_hist_sw`/成分接口，按日期点取）再补。方案文档需将此从"缺口清单"升级为"P0 阻塞项决策"。

### R2-2 [HIGH] C 因子边界规则未定义 → 隐性选样

三个具体漏洞：
1. **负基数增速**：去年同期扣非为 -0.01 亿 → 本期 +0.05 亿时同比 = +600%，垃圾反转股混入"高成长"
2. **零基数**：去年同期恰为 0 → 除零
3. **上市不足 3 年**：A 因子的"连续 3 年年度增长"无法计算——次新股是 A 股高波动主力，处理方式（剔除 or NaN or 缩窗）直接改变样本构成

**修正**：写入方案 §3.1 规则表——负基数或 |基数|<阈值(如 0.05亿) 时增速置 NaN；连续增长计数允许 min_periods=2 但记录覆盖率；次新股单独标记做有/无对照组。

### R2-3 [HIGH] 公告节奏造成的调仓时点拥挤效应

A 股披露制度：年报截止 4/30 且一季报同期密集披露。桥接对公告缺失行用固定月偏移兜底（Q1+3mo/Q4+4mo）。结果：**5 月初会有巨量股票同时满足 C 条件刷新**，月度调仓恰好踩在这个脉冲上；反之 2-3 月是信息真空期。方案未讨论这种季节性供给冲击对等权组合的影响（买入价差、涨停买不进的聚集）。

**修正**：组合轨增加"公告事件驱动的调仓时点对照实验"（月初 vs 公告后 N 日滚动调仓），或至少报告每月入选数量的时间分布图。

### R2-4 [MEDIUM] M 开关的实现细节风险

MA200 在 2016-2026 沪深300 上大约翻转 8-12 次，月度检查粒度下单次滞后可达 ±20 个交易日的择时误差；RegimeDetector 有 fail-open 记录（NaN→UNKNOWN）。方案承诺"M 降低最大回撤 ≥10pct"(H5) 但未定义 M-OFF 时行为：清仓 or 半仓（申万用半仓）？两者回测结果差异巨大。

**修正**：M 定义三要素写死——信号=沪深300收盘>MA200；粒度=每日计算、月调仓执行+止损独立触发；OFF 行为=半仓（主）/清仓（对照）。

### R2-5 [MEDIUM] 止损与 T+1/跌停的执行现实性

-8% 止损触发当日若跌停封板无法成交（T+1 也禁止当日卖入），实际止损价显著劣于回测假设。unified_engine 已有涨跌停约束，但组合轨脚本是否复用该约束未写明。

**修正**：明确组合轨复用 `UnifiedBacktestEngine` 约束集；跌停不可卖时顺延至次日，止损滑点纳入费用模型。

### R2-6 [LOW] 费用口径

双边千 1.3 高估买入侧（佣金~万 2.5 无印花税）、低估卖出侧（印花税万 5 + 过户费）。建议改精确费率函数（项目已有 `shared/cost_model.py`），避免"费用打平超额"的争议。

### R2-7 [LOW] S 因子退化后名不副实

S 只剩"放量确认"，与 N 的突破确认高度重叠。建议一期干脆合并为 "N+S: 近新高∧放量"单一条件，减少一个自由度。

## B1 蓝队辩护

### B1-1 定位切换有正统先例，非逃避证伪 ✅

条件排序/交互效应在文献中是标准方法（Fama-French 双重排序、条件动量、event-study 组合法）。关键在于：方案并未豁免验证——系统层仍有组合级验收门（超额>0、IR>0.5、分年稳健≥60%）+ 归因分解 H6。这与 Wyckoff 教训（相位当方向、单窗小样本当结论）相反，是**正确的评估对象切换**。蓝队裁定：指控不成立，但须加一条防火墙——**系统层若失败同样终止路线**（方案已有失败预案，予以确认）。

### B1-2 预注册框架是本项目的实质进步 ✅（附 R1-2/R1-3 修补）

Wyckoff 研究是"多轮对抗后才补预注册"，本次先于任何回测写下 H1-H6 + 失败预案，流程上前进了一步。修补点见红队 R1-2（H3 双向化）与 R1-3（参数冻结）。

### B1-3 与现有管线兼容成本可控 ✅

- 因子轨：`run_logic_factor_test.py` v2 已支持自定义因子列表+动量残差门，新增 5 个因子注册即可跑
- 财务因子进面板的唯一新工程量 = bridge merge_asof 后的对齐管线（P4 已具备零件）
- 组合轨需新建（估计 ~300 行），但约束集可直接 import unified_engine 的规则函数

### B1-4 数据缺口分级正确 ✅

S/I 缺失是降级项非致命项：I 有明确二期路径（`stock_institute_hold` 实测可得）；S 合并入 N 后损失有限。真正致命的是红队指出的**幸存者偏差**与**行业过滤**两项（已列为 CRITICAL）。

### B1-5 MVP 设计建议

两周内可完成的最小生死判定实验：
1. **D+2**: 冻结参数 + 写入负基数/新股边界规则 + 金融规则过滤
2. **D+4**: C/A 两因子走完因子轨四重门（含事件法并行判据）→ **若双败，路线即刻终止**（最高信息量的早期出口）
3. **D+9**: CA-only vs CALN 两组组合回测（2016-2021），M on/off 各一遍
4. **D+14**: 2022-2026 一次性终验（OOS）+ 归因报告 + 幸存者偏差下界标注

这个 MVP 把最大的不确定性（成长因子是否有效）放在最早、最便宜的检验点上。
