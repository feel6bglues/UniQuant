## 1. 文献调研综述

### 1.1 原版规则（IBD 官方 + 《笑傲股市》第4版）

| 字母 | 官方量化标准 |
|---|---|
| **C** 当前季度收益 | 当季 EPS 同比 **≥25%**（最佳者 50-100%+，且逐季加速）；当季营收同比 ≥20-25%；ROE ≥17% |
| **A** 年度收益 | 年度 EPS **连续 3 年增长**；近 5 年复合增速 ≥24-25% |
| **N** 新事物/新高 | 新产品/新管理层/新产业趋势（定性）；**股价距 52 周新高 ±15% 以内**（可量化的主体） |
| **S** 供给/需求 | 流通盘小（美股口径 <2500 万股）；突破伴随**成交量显著放大** |
| **L** 领涨/落后 | **RS Rating ≥80**（12 个月相对价格强度、近 3 月加权、全市场 1-99 百分位）；行业组前 40-50 |
| **I** 机构认同 | 机构持仓 **≥10 家**且环比增加；避免过度持有 |
| **M** 市场方向 | 指数站上关键均线（趋势确认）；四分之三股票跟随大势 |

卖出纪律：**个股 -7~8% 止损**（O'Neil 铁律）、突破失败离场、涨幅放大阶段分批止盈。

### 1.2 O'Neil Global Advisors 官方实证（RS Rating 白皮书, 1995-2020）

- RS Rating 构造：12 个月累计价格表现 + **最近 3 个月额外加权**，全市场百分位排名
- 五分位组合单调递增；Q5 年化 15.5%（波动调整口径）vs Q1 2.55%；**Q5 Sharpe 0.66 vs Q1 0.10**
- 多空 Q5-Q1 市场中性组合统计显著——RS 是其数据库中被验证最强的单一评级

### 1.3 A 股本土化回测对比

| 来源 | 规则要点 | 区间 | 结果 | 备注 |
|---|---|---|---|---|
| **华创金工** | 当季EPS≥18%、季销≥25%、5年常续复合≥15%且逐年正、1年新高、RPS≥80、机构≥10家或外资≥5%；月调仓等权，费率双边千1.3 | 2012.01-2019.10 | **年化 21.5% vs 中证500 5.5%，超额16%，IR 1.03**；最大回撤 45.5%（2015股灾） | 持仓集中医药生物(20%)，市值中位数 220 亿 |
| **申万宏源** | 剔除最小市值20%；"基底"形态池内选 RPS前2/3 × 营收增速前1/3 × 机构持股增长前1/3；**沪深300年线下仓位降至50%** | 2005.01-2017.12 | 年化 29.64% vs 沪深300 11.79%，夏普 0.99；平均每期仅 25 只 | "基底×基本面×技术面共振"；选股数波动大(0~127只) |
| **程序化老手** | EPS同比>18%+ROE>15%；箱体突破(±10%箱体+10%动量)；**M 用 -7% 组合止损替代** | 2007-2011.09 | 累计 647% vs 沪深300 39%；2008 年仅亏 14%（市场 -65%） | 止损贡献主要超额 |
| **台湾学位论文** | 直接按门槛筛选 vs 放宽为 C/A/L 三指标或 C/A 二指标 | 多窗口 | **严格七条件几乎选不出股票；放宽后也未必跑赢指数；持有 3-6 个月表现较好** | 对门槛刚性提出质疑 |
| **连板网（14年回测）** | RPS 多周期评级落地 | 2010s 全样本 | ⚠️ **"A股整体呈反转结构，追强策略跨年代普遍不占优；RS 工具甜区在弱市与结构市，全面牛市钝化；需加环境开关"** | 与本项目 P3 结论独立收敛 |

### 1.4 调研小结

1. CANSLIM 在 A 股的回测证据**存在但高度依赖时段与实现细节**；三家正结果均来自 2019 年前样本
2. 共识性适配：C 用**扣非**净利润、A 要求连续多年、N 取"接近新高"、L 用 RPS80、I 用机构数、M 是**最重要的风控开关**
3. 关键警示与我们自己的实证一致：**A 股是反转市，纯追强有结构性风险**

## 2. 与本项目已有结论的衔接

### 2.1 已就绪的基础设施

| CANSLIM 组件 | 本项目对应资产 | 就绪度 |
|---|---|---|
| C/A 财务计算 | `data/lake/financial/` 5211只×42季 + `FinancialFactorBridge`(EPS_TTM/PE_PB/公告日防前视) | ✅ 本期完成 |
| L 相对强度 | Wyckoff `rs_classify` 四分类 + P1 净化行情池 | ✅ |
| M 市场方向 | `RegimeDetector` + 000300.SH 指数数据 | ✅ |
| N 新高 | 行情池 rolling max | ✅ |
| 四重门验证管线 | Walk-Forward 504/63 + IC/PBO/动量残差门 (`run_logic_factor_test.py`) | ✅ |
| 组合回测 | `UnifiedBacktestEngine`（T+1/涨跌停/费用约束齐备） | ✅ |

### 2.2 必须直面的矛盾：CANSLIM-L/N vs 我们的动量证伪

P3 实证（500 只 × 17 窗）：控制 20d 动量后所有价量因子残差 IC 归零或翻正；连板网 14 年回测独立得出"A股反转结构、追强不占优"。而 CANSLIM 的 L(RPS) 和 N(新高) 就是 12 个月动量。

**但两者并不直接矛盾**，因为评估对象不同：
- P3 评估的是"横截面排序器的独立预测增量"
- CANSLIM 是**多条件合取的事件筛选器**：C/A×L/N×M 同时满足的稀疏集合（申万实测平均每期仅 25 只），其有效性可以来自"成长基本面 × 动量确认"的交互项，而非任一单因子的边际贡献
- 券商回测的超额也可能主要来自 M(择时/止损) 或 C/A(成长)，而非 L/N

这正是本方案要用实验拆解的问题，而不是预设结论。

## 3. 七因子 A 股量化定义与数据映射

### 3.1 C — 当前季度成长（财务底座直接可算）

| 指标 | 定义 | 数据来源 | 门槛 |
|---|---|---|---|
| 扣非净利同比 | `(扣非净利_最新TTM季 / 扣非净利_去年同期TTM季 - 1)`，公告日 merge_asof 防前视 | financial parquet: `net_profit_deducted` | ≥25%（研究区间放宽至 ≥18% 做敏感性） |
| 营收同比 | 同法，`revenue` | ✅ | ≥20% |
| 加速项 | 最近两季扣非增速环比上升 | 同上 | 可选加分 |
| ROE | `净资产收益率` | ✅ | ≥15%（原版 17%） |

注意：金融行业科目差异 → 行业过滤；单季值由年边界差分（桥接已修复同款逻辑）。

### 3.2 A — 年度成长

| 指标 | 定义 | 门槛 |
|---|---|---|
| 连续增长 | 近 3 个年度 EPS（或归母净利）逐年为正增长 | 必要条件 |
| 复合增速 | 3 年扣非复合 ≥25%（敏感性下探 15%） | 主条件 |
| ROE 持续 | 近 3 年年报 ROE 均 ≥13% | 辅助 |

### 3.3 N — 接近新高（价格维度）

- 定义：`close / rolling_max(close, 252) ≥ 0.85`
- "新产品"维度不可量化 → 不做（如实记录）
- 变体：距离新高 ≤10%/15%/20% 敏感性

### 3.4 S — 供给/需求（受限）

- ❌ 流通市值：**数据缺失**（无股本列）→ 无法复刻"剔除最小市值 20%"与"小盘偏好"
- ✅ 可做：突破日成交量 ≥ 20 日均量 × 1.5（量价确认）；成交额横截面分位过滤流动性
- 二期若补股本数据（akshare `stock_zh_a_spot_em` 有总市值/流通市值现价快照，但历史序列难），再升级

### 3.5 L — RPS 相对强度

- 复刻 OGA 官方构造：过去 12 个月收益，**近 3 月加权**（权重 2×3月/2×6月/1×9月/1×12月 或直接 0.4/0.2/0.2/0.2），全市场百分位 ×100
- 门槛 ≥80；对照组：不加权 12 月收益 RPS
- **预期风险**：此因子将撞动量残差门——按 §4 策略处理

### 3.6 I — 机构认同（二期）

- akshare `stock_institute_hold(quarter)` 全市场机构数/持股比例/增幅（2005 起）✅ 可得
- 定义：机构数 ≥10 且 机构数环比增加 >0
- 一期不做（避免同时引入新数据源与新策略两个变量），列为 P1 扩展

### 3.7 M — 市场方向（风控开关）

- 基础版：沪深300 收盘 > MA200 → 风险开启（ON）；否则 OFF（空仓/半仓）
- 进阶版：复用 `RegimeDetector` 输出
- 回测对照：M-ON/OFF 分层 + 华创式"年线下仓位50%"

## 4. 核心矛盾的处理策略

### 4.1 定位声明

**CANSLIM-A股方案定位为"事件筛选器 + 择时开关"，不是横截面因子排序器。** 验收标准相应调整为：

- 层次一（因子层）：C/A 各自作为因子过四重门（预期可通过——财务与动量结构性正交）
- 层次二（交互层）：L/N 在**控制 C/A 之后**的增量贡献（条件 IC / 组合分层），不要求其独立过动量残差门
- 层次三（系统层）：完整 CANSLIM 组合 vs 基准的组合级指标（年化/夏普/回撤/换手），月调仓、双边千 1.3、T+1/涨跌停约束

### 4.2 预注册假设（防数据窥探，先于任何回测写下）

| 编号 | 假设 | 判定 |
|---|---|---|
| H1 | C（扣非增速）单独通过四重门 | IC>0, ICIR>0.5, PBO<0.2, 动量残差通过 |
| H2 | A（年度成长复合）单独通过四重门 | 同上 |
| H3 | L/N 独立 IC 为正但**不过**动量残差门（复现 P3） | 若意外通过则记录为新发现 |
| H4 | L/N 在 CA 条件子集内的组合增量 > 0 | CA-only vs CALN 组合年化差 |
| H5 | M 开关降低最大回撤 ≥10pct | M-on/off 对照 |
| H6 | 完整系统超额为正且主要来自 C/A+M，而非 L/N | 归因分解 |

### 4.3 失败路径预案

- 若 H1/H2 也失败 → 成长因子在净化真实数据同样无效 → 如实记录，CANSLIM 路线终止（与 P2/P3 同样的负结果纪律）
- 若仅 H4 成立 → 最终方案 = "CA 选股 + LN 时序确认 + M 择时"，明确归因
- 严禁在看到结果后修改门槛/窗口（预注册纪律，同 Wyckoff P2 门流程）

## 5. 验证方案（双轨）

### 5.1 因子轨（复用现有管线）

- 面板：500 只 seed=42 × 1600 交易日，as-of 2026-05-29，504/63 窗
- 新因子注册：`c_deducted_growth_ttm`、`a_compound_growth_3y`、`roe_avg`、`n_near_high_252d`、`rps_weighted_12m`
- 四重门：IC 方向 / ICIR / PBO / 动量残差（`run_logic_factor_test.py` v2 架构直接扩展）
- **公告日防前视**：财务因子经 bridge `merge_asof` 后进入面板（P4 已具备）

### 5.2 组合轨（新建脚本）

```
scripts/canslim/run_canslim_backtest.py
  ├─ 月度调仓（每月首个交易日）
  ├─ 筛选: [C∧A] → [可选+N] → [可选+L] → [M-ON 才建仓]
  ├─ 等权、个股≤5%、双边千1.3、涨停不可买/跌停不可卖、T+1
  ├─ 个股 -8% 止损（原版铁律）
  ├─ 对照组: C / CA / CAN / CALN / CALN+M / 基准(中证500 & 等权全池)
  └─ 输出: 年化/夏普/最大回撤/IR/换手率 + 分年表 + 归因(H1-H6 判定)
```

### 5.3 验收标准（组合轨）

| 门 | 标准 |
|---|---|
| 超额 | 全样本年化超额（vs 中证500）> 0 且 IR > 0.5 |
| 稳健 | 分年超额 ≥0 的年份占比 ≥60% |
| 风控 | 含 M 版本最大回撤 < 无 M 版本 |
| 归因 | H1-H6 逐项给出 PASS/FAIL，不允许事后改门槛 |

### 7.3 金融股识别决策（修正案 A2）

一期采用**静态名单**：取 akshare 当前行业快照中的银行/证券/保险成分码，冻结为常量文件 `scripts/canslim/financial_codes.json`。前视安全性论证：该三类公司的行业归属在 2016-2026 全样本期内稳定（银行不会变成非银行），故"今日快照"用于历史过滤无信息泄漏；反之动态科目规则（杠杆×周转率）误判率高且引入额外自由度。

### 7.4 H3 修订（中性双向判定）

原 H3"预期 L/N 不过动量残差门"改为：**H3: L/N 的独立四重门结果如实记录（双向开放）**。L/N 进入最终系统的唯一依据为 **H4（CA 条件子集内的组合增量 > 0）**，与其是否符合预期无关。

### 7.5 因子层双判据（R1-4 采纳）

C/A 除日频横截面 IC 外，并行计算**季频事件法**：以公告日为事件、按因子分位分层的 FwdRet(21d/63d) 多空差。两判据冲突时以事件法为主并显式说明。

### 7.6 幸存者偏差义务（A1）

组合轨报告必须包含：(a) 各期"在市但无财务数据"比例（baostock 历史快照量化）；(b) 最坏情形收益下界（缺失股收益 ∈ [-100%, -60%] 情景）。未含此节的回测结果视为无效。

### 8.2 判定与发现
