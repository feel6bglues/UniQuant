## 核心实证结论（沪深300 口径，2010–2024 年报 → 次年收益）
- **ROE 是 300 只大盘股上的显著负因子**（IR -0.591）：质量越好→估值透支→超额越差；15 只龙头样本弱负（IR -0.07）。**核心打分必须剔除 ROE**。
- **现金含量 OCF/NP 是最强基本面因子**（300 只 IR 0.656；全A 1.65）；FCF_Yield 0.374、真实 DY 0.315 稳定正；SUE≈0 无效；EP 0.192 弱正。
- 牛熊拆分：价值/红利 alpha 主要来自**熊市防御**（DY 0.20/FCF 0.12/现金含量 0.14），牛市钝化。
- 2024-02 微盘崩塌：ROE rankIC=+0.22（质量因子防御属性，验证 v2 §9.5）。

## 组合与风控
- **WS2 最优组合**（沪深300）：核心_无ROE（DY+FCFY+现金含量 Top30）+ 动量25% + 低波25%，等权 1/3 夏普 **0.504**（2014-01~2026-08），跑赢 HS300 等权(0.448)/指数(0.166)。含 ROE 核心夏普 -0.11（毒药）。
- **V2 季频升级（HS300）**：TTM 因子 + 5/9/11 月调仓 → 夏普 0.465→**0.494**、回撤 -40.3%→**-28.4%**、Calmar→0.432。季频价值=回撤控制。
- **V2 全A 真实 DY 颠覆发现**：全A 年频真实 DY 夏普 **0.312** vs 近似 DY(30%) **0.398**——**近似 DY ≈ EP 代理（盈利暴露幻觉）**；真实 DY 把红利组收敛到银行/煤炭（样本期跑输）。HS300 真实 DY 增强（大盘分红率≈30% 失真小）。**全A 核心改"现金含量+FCFY+EP"，剔除红利权重**。
- **WS4 拥挤度** = mean(估值拥挤=100−分位(红利组合DY), 成交占比分位, 放大幅度分位)，滚动 36 月分位。**HS300 熔断按任一维度极端触发**：方案A（≥75减半/≥85清仓）夏普0.389/Calmar0.313；方案B（任一维度≥90/≥95）回撤-28.1%。rankIC=-0.232。2026-04 估值拥挤 100 分位（历史极值）未放量——高位钝化警告。
- **V2 全A 拥挤度**：方案A 夏普 0.297→0.347、回撤-47.8%→-45.0%；**方案B 全A 过度防御**（触发47月反伤）。**口径依赖：全A 红利 2026-04 估值拥挤仅 33 分位（vs HS300 100 分位）——按投资篮口径监控**。rankIC -0.281（强于 HS300）。
- **V2 CANSLIM 否证（HS300）**：五因子（含真实季报C）夏普 0.307 < 基准 0.448，与动量相关 0.817、核心组合 0.748——无正交增量。**坑：N/L 价格因子用当月价=未来函数（虚假夏普 4.84），必须用上月末价基准**。
- **V2 LPPL 泡沫监测**：2026-08 评分 75/100、m=0.06 泡沫加速期，与 WS4 拥挤度共振（双重风控齐亮）；历史验证 2015/2020-21 正确。tc 临界时间估计不稳（m→0 退化），仅定性用。
- FCF 正交化结论：FCF 的 alpha 几乎全部来自价值(EP/DY)暴露，控制后残差 IR -0.285，**非"质量/红利进化版"**（15 只口径）。

## V3 最终实盘画像（2026-08-27 P0 验证后，最新结论优先）
- **实盘方案**：全A 季频核心（现金含量+FCFY+EP，EP 带季度滚动 IC 失效监控）+ 低波40% + **HS300 月线 MA12 趋势降仓50%**（价<MA12 时核心收益×0.5）。预期夏普 0.33-0.36、回撤 ~-40%。
- **Walk-forward 定论**：IS 2014-2018 夏普 0.229 → OOS 2019-2026 **0.496**（样本外反向增强，无过拟合衰减）；现金含量 14 次滚动决策全入选（IC 0.044-0.063 最稳）；**EP 2023 起失效（2026 IC -0.066）需滚动监控降权**。
- **趋势风控**：MA12 降仓50% 夏普 0.348→0.350、回撤 -50.0%→-43.8%、2018 熊市 -30%→-19.8%；清仓版牺牲收益（0.234）换更强防御。触发 43% 月份。
- **风险画像（对抗修正）**：全A 现金流价值因子是**高风险 beta 因子**（2018 熊市 -30% vs 等权 -5.7%、2015 -15.7 vs -9.3、2022 -6.6 vs +7.3），仅 2024-02 微盘崩塌防御（+9.2 vs -3.6）——"防御属性"叙事仅限 HS300 口径。夏普显著性 t=1.5/p=0.13（全样本不显著，OOS 段显著提升）。
- **口径分离刚需**：HS300 大盘价值（熊市防御）vs 全A 现金流（熊市崩溃）是相反风控画像，各配各的风控（HS300 用拥挤度熔断、全A 用 MA12 趋势降仓，不可互换）。

## 纪律
- PIT：年报 t → 次年 5 月调仓（4 月底披露完）；季频 5/9/11 月；禁 end_date 对齐
- **因子滞后纪律**：价格类因子（动量/新高/相对强度）必须用上月末价，禁止当月价（未来函数）
- 断点续传拉数，失败不丢数据；免费 API 配额有限（妙想已证实）
- 幸存者偏差：成分股用当前时点列表，历史回测未做成分调整，已披露
- 布尔分组筛选直接 `df[df[col]>med] if hi else df[df[col]<=med]`（`(cond)==bool` False 分支会反转选错）
- 全A 规模：财报匹配用 (code,period) dict 索引；gpcw CSV 无派生列需自算
