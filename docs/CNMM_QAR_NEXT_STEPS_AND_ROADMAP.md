### 阶段一（第 1–2 周）：交易柜台网关接入与纸面实盘（Paper Trading）联调
*目标：打通 UniQuant 到证券与期货柜台的实际 API 链路，用实盘真实 Tick 检验订单状态机。*
1. **柜台接口适配与选型**：
   - **期货端**：接入标准 CTP API（中金所 IF/IC/IM 合约行情接收与套保交易通道）；
   - **现货端**：接入券商极速柜台（迅投 QMT 或恒生 PTrade Python API）。
2. **纸面模拟撮合与状态机实战**：
   - 将本次已落地的 [`order_state_machine.py`](file:///home/james/Documents/Project/CNNM/scratch/order_state_machine.py)（SQLite WAL 架构）接入实盘模拟环境；
   - 在交易时段通过 3 日 OFI-TWAP 算法发送虚拟切片挂单，实测订单流不平衡（OFI）实时计算时延（要求盘口响应 $<50\mu s$），检验 65% Maker 挂单成交率是否符合预期。
3. **交付物**：
   - `src/uniquant/hands/gateways/ctp_gateway.py`（CTP 期货网关接口）
   - `src/uniquant/hands/gateways/qmt_gateway.py`（QMT 现货网关接口）
   - 纸面模拟盘 10 个交易日滑点与成交率对账报告。

### 阶段二（第 3–4 周）：生产级自动化调度中台与法医每日巡检
*目标：摆脱人工脚本触发，实现财报季法医扫雷、因子计算与调仓生成的无人值守全自动运行。*
1. **日度/季度自动化调度流（Airflow / Prefect）**：
   - **每日 16:00**：盘后拉取行情更新 `quotes/daily/`，自动检查是否有除权除息（GBBQ）事件；
   - **财报披露期（4/8/10月）**：自动拉取披露财报，调用 [`z_cnmm_calculator.py`](file:///home/james/Documents/Project/UniQuant/src/uniquant/brain/factors/forensics/z_cnmm_calculator.py) 执行行业内 MAD 鲁棒打分与 CashTrap 检验，自动生成当期**高危黑名单（Blacklist）**与**清洁安全白名单（Whitelist）**；
2. **实时风险监控哨兵（Risk Sentinel）大屏**：
   - 实装 **MLSI（市场流动性压力指数）** 实时监控探针；
   - 设定**保证金占用阶梯预警线**：
     - 占用率 $\ge 70\%$：触发飞书/企业微信二级预警，启动 PB 质押额度准备；
     - 占用率 $\ge 85\%$：触发一级风控，启动 30 秒内对冲仓位阶梯下调至 50% 的自动平仓避险程序。
3. **交付物**：
   - `dags/cnmm_daily_market_pipeline.py`（自动化调度 DAG）
   - `src/uniquant/risk/sentinel/mlsi_monitor.py`（实时风控大屏）
   - 每日盘后自动推送到钉钉/飞书的资产风控报告模版。

### 阶段三（第 5–6 周）：机构合规申报与券商 PB 跨市场质押授信
*目标：在法律与合规框架下，为 10亿~50亿 AUM 规模扫清制度障碍。*
1. **中金所套保专用编码（Hedging Quota）申请**：
   - 按照 [`cffex_quota_and_twap_execution_engine.py`](file:///home/james/Documents/Project/CNNM/scratch/cffex_quota_and_twap_execution_engine.py) 的方案，向中金所提交现货股票组合底仓证明；
   - 申请 3 个机构套期保值交易编码，分配单边空头持仓限额至 1,042 + 1,042 + 1,041 手，彻底规避 1,200 手投机限额封锁。
2. **券商 PB 跨市场蓝筹质押协议签署**：
   - 与托管券商（PB）签署现货蓝筹 70% 折算率质押授信协议；
   - 确保当市场发生单周暴涨超 20% 时，现货资产可**实时作为期货保证金增信垫**，从制度上阻断银证 T+1 转账流动性死锁。
3. **交付物**：
   - 中金所套期保值额度正式批复文件；
   - 券商 PB 跨市场质押增信服务协议与实时质押额度划拨接口。

### 阶段四（第 7–12 周）：种子资金沙盒试运行与微观微调
*目标：用小规模真金白银验证实盘滑点、对冲跟踪误差与投资者实际体验。*
1. **小规模资金灰度孵化（Seed Capital）**：
   - 建议首期投入 **1,000 万 ~ 3,000 万元** 自有种子资金启动沙盒试运行（对应 6~18 手 IF 对冲合约）；
2. **实盘微观跟踪与归因分析**：
   - 记录每日实盘对冲基差损耗（Basis Carry）与理论值的偏离度；
   - 记录 3 日 OFI-TWAP 的实际执行滑点（检验是否能够持续稳定在 0.5 bps 以内）；
   - 检验私募 2/20（ACT/365 计提与 6% 门槛年化高水位）估值账本的账实核对无误。
3. **交付物**：
   - 连续 3 个月实盘日频净值审计表与对账报告；
   - 实盘对冲跟踪误差（Tracking Error）与滑点摩擦归因审计报告；
   - 50 亿 AUM 规模化资金准入与募资开放备忘录。
