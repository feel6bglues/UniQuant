#### 4. `P0.1` 的 lookahead 检测算法需要换成因果扰动法

原计划中“通过与滞后版本的 rank 相关性对比”属于启发式检测，可能漏报，也可能误报。测试中 dirty 函数是：

```python
x["momentum"] = x["close"].shift(-1)
```

更稳妥的实现是因果扰动法：

1. 先对原始数据运行 `factor_func` 得到基准因子。
2. 选择多个 cutoff date。
3. 对 cutoff 之后的未来价格列做大幅扰动或截断。
4. 重新运行 `factor_func`。
5. 比较 cutoff 当日及之前的因子值是否改变。
6. 若历史因子受未来扰动影响，抛出 `LookaheadBiasError`。

修订要求：

```text
check_lookahead_leakage 不应依赖相关性猜测，应使用未来扰动不变性校验。
```

验证命令：

```bash

```
