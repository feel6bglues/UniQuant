## 1. 发现的问题

### 1.1 🔴 F07, F08 混淆了"架构层数"与"引擎数"——应删除

**文件**: `docs/docs_fix_plan.md` §3.7

**修复计划声称**:
> F07: `whitepaper/ARCHITECTURE_WHITEPAPER.md:3` — "8 层" → 改为 "8 层 9 引擎"
> F08: `whitepaper/DEPLOYMENT_GUIDE.md:12` — "8 层" → 改为 "8 层 9 引擎"

**代码事实**:

`ARCHITECTURE_WHITEPAPER.md:3`:
```
> **当前完成度**: ~100% (269 文件, ~59,441 LOC, 8 层全部就绪, 1034+ 测试)
```

`DEPLOYMENT_GUIDE.md:12`:
```
**当前状态**: Phases 0-6 全部完成。~269 文件, ~59,441 LOC, 1034+ 测试通过, 8 层全部就绪。
```

**评价**: 这里的 "8 层" 指的是架构指定的 **8 层体系** (shared/data/brain/signal/risk/hands/services/ui)。这 8 层在 `src/uniquant/` 中的确全部存在——不是 7 层, 不是 9 层, 是确实的 8 层。 引擎数是 engine_factory 注册的 **9 个引擎**, 是 brain 层内的子计数。

**"8 层" = ✅ 正确**。修改会引入错误。

**裁决**: ❌ 删除 F07 和 F08。原文本完全正确。
