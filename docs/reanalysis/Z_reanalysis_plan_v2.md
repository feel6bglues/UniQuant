## 本轮分析设计原则

1. **不重复已有结论** — 直接引用前两轮分析结果，聚焦未被覆盖的维度
2. **行为优先于结构** — 关注运行时行为、边界条件、规模下的退化
3. **量化证据** — 每个结论绑定具体指标（行号、测试名、时间、频率）
4. **可执行输出** — 每个阶段产物包含具体的修复/改进 PR 模板
5. **红蓝对抗** — 每个阶段内建挑战-辩护机制，防止分析盲点
